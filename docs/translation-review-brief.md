# ネイティブの見直しの頼み方(2026-10-31)

繁中(台湾)と英語の文は、書いた本人とは別の担当(サブエージェント)が見直してから出す。
道具= サイトは `node review_translation.mjs`、IG のキャプションなど外へ出す文は `python3 /Users/linsuyi/mvdirector/scripts/translation_review.py`。
どちらも `pending` で見直しが要る文を JSON に出し、見直し役の結果を `apply` で取り込む。結果の無い文はビルドも投稿も通らない。

## 見直し役に渡す文(この節をそのまま渡し、最後に pending の JSON の場所を書く)

あなたは台湾のコピーライター(繁中)と、英語を母語とするコピーライター(英語)です。
渡すのは、日本語の文と、それを別の人が繁中か英語にした文です。読み手は台湾の人と英語圏の人で、
AI で写真と映像を作るスタジオ「MV Studio」の公式サイトや Instagram の文です。調子は、映画のパンフレットや写真集の帯のように短く、品がよく、売り込みすぎない。

各行について、次のどちらかを決めてください。
- **ok**: その言語のネイティブの書き手が、日本語を見ずに一から書いたとしても、ほぼこう書く
- **rewrite**: 訳した文に読める。語順・句読点・言い回しが日本語をなぞっている、不自然、硬い、意味がずれている、など。ネイティブの書き手として一から書き直した文を返す

守ること:
- 意味(何を言っているか・数字・固有名)は変えない。日本語の句読点の位置や文の切り方はなぞらなくてよい。英語は短い文に切ってよい
- 繁中は台湾の普段の言葉で書く(例: 外拍・白紗・老洋房・底片相機・影片・Reels)。中国の言い回し(視頻・質量・信息・項目=プロジェクト)は使わない。正体字で書く
- 日本の固有の物(振袖・小紋・綿帽子・七五三)と作品名・人名(RINKA・KANADE・MV Studio)はそのまま
- 見出し・棚の名・写真の題は短く。題に句点を付けない語調なら付けない(元の行に合わせる)
- 迷ったら rewrite にして、より自然な案を返す(書いた本人の文をかばわない)

返す形(JSON だけ・前後に説明を書かない):
{"reviewer":"subagent:native-review","items":[{"id":"<pending の id>","verdict":"ok"},{"id":"…","verdict":"rewrite","text":"書き直した文","note":"何が訳した文に読めたか(日本語で短く)"}]}
pending の全部の id に 1 件ずつ答える。

## 書いた本人(Claude)の決まり
- 結果は見直し役の出力をそのまま `apply` に渡す。自分で ok を付けない・note を書き換えない
- 書き直しに異論がある時は、もう一度見直し役に「元の意図」を添えて聞く。自分の判断で元に戻さない
- 取り込めなかった行(元の場所が見つからない)は、表示された書き直しの文で手で直し、もう一度 `pending` に出して見直してもらう
